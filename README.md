# AI Saurabh VoiceBot

AI Saurabh VoiceBot is a personalized AI-powered voice assistant that simulates my professional profile, achievements, projects, and interview responses. The application supports voice input, AI-generated responses, and voice output, providing an interactive conversational experience.

## Live Demo

Frontend: https://ai-saurabh-voicebot.vercel.app

Backend: https://ai-saurabh-voicebot.onrender.com

## Features

* Voice Input using Speech Recognition
* AI-Powered Responses using Google Gemini
* Voice Output using Browser Speech Synthesis
* Personalized Interview Assistant
* Real-Time Question Answering
* Public Deployment with Vercel and Render
* FastAPI Backend
* Next.js Frontend

## Installation

### Clone Repository

```bash
git clone https://github.com/SAURABHRAJVARMA/ai-saurabh-voicebot.git
cd ai-saurabh-voicebot
```

### Backend Setup

```bash
cd backend

pip install -r requirements.txt
```

Create a .env file:

```env
GEMINI_API_KEY= it's personal
```

Run Backend:

```bash
uvicorn main:app --reload
```

### Frontend Setup

```bash
cd frontend

npm install
npm run dev
```
